# HE3 七轴下午测试入口

1. 打开本目录的 `RopeEncoderCalibrationTool.sln`。
2. 选择 `Debug | x86`，重新生成解决方案；必须是 0 个错误。
3. 将 `RopeEncoderCalibration` 设为启动项目并按 F5。
4. 界面应默认显示 `HE3_GY`、`拉线编码器`、60 个七轴点位和速度 20。
5. 严格按 `HE3实机测试操作说明.md` 完成连接、读取拉线零点、回零确认和 60 点采集。
6. 第 60 点后程序会自动调用 `CalibrationV2`，弹窗明确显示“计算通过”或“结果被拒绝”。
7. 通过条件：DLL 状态成功，全部点和留出验证点的拉线平均残差均不大于 1.0 mm，参数未触及 ±5 mm / ±1° 安全边界。
8. 本版本只计算和保存报告，七轴参数写回保持锁定。

结果必须连同以下文件一起保存：

- `log/MachineTest_*.log`
- `Joint/HE3_GY_Joint_*.txt`
- `data/HE3_GY_Data_*.txt`
- `Result/CalibrationV2_HE3_GY_*.txt`

注意：拉线残差合格不等于三维绝对定位精度已经合格，最终仍需独立计量验证。
