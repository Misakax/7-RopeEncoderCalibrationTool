# HE3 拉线标定 V3 R6.1 分析与使用说明

## 版本定位

- 构建号：`HE3-V3-V1-ANALYTIC-20260821-R6.1`
- 工程：`HE3_RopeCalibration_V3.sln`
- 交付配置：`Release | x86`（生成 Win32 上位机和 DLL）
- R6.1 继续使用 V1 的 MDH 正运动学与解析参数雅可比，不改成数值差分量产算法。

## R6.1 相对 R6 的核心改动

R6 把 HE3 当前可辨识集合设为 `d2～d5、alpha2～alpha6、q2～q5`。R6.1 没有凭主观判断强行加入 q6，而是在每次计算前使用精确解析位置雅可比检查 q6 列：

1. q6 列非零时，自动让 q6 参与辨识；
2. q6 列为零时，保持机械设定值，不把零列塞进最小二乘；
3. q7 始终作为当前轴向挂点模型的结构零列检查项，不参与辨识；
4. 上位机迭代窗和 CSV 日志新增 q6/alpha6/q7 的 RMS 敏感度、q6-alpha6 余弦相关度及 q6 是否启用；
5. 量产保存门限同时检查上述可观测性结论。门限未通过时禁止保存和写回机器人。

## 为什么当前 q6、q7 都固定

这里的“无法辨识”不是说关节不能旋转，而是说：在当前 MDH 和测量点模型中，改变该关节零位不会改变被计算的拉线挂点位置，因此所有拉线长度都不变。

解析位置雅可比验证结果：

```text
q6 point-Jacobian column norm = 0
q7 point-Jacobian column norm = 0
```

把 q6 人为注入 `+0.5°` 后，模型产生的 96 个拉线长度仍完全不变，求解矩阵秩为 `0/1`。因此强行“解放 q6”只会制造欠秩，并不能估出真实零位。R6.1 根据解析雅可比自动作此决定；以后如果末端测量模型改成离轴点，q6 列变为非零，它会自动进入辨识。

这不代表所有旋转轴都不能标定。q5 注入试验证明：

```text
q5 注入：0.500000°
q5 恢复：0.49998755°
rank：1/1
```

因此真正原则是“一个参数是否会在现有测量中留下独立的长度变化指纹”，不是“旋转轴一律固定”。

## 当前参数集合

当前 HE3 轴向挂点模型下，正常启用：

```text
d2、d3、d4、d5
alpha2、alpha3、alpha4、alpha5、alpha6
q2、q3、q4、q5
```

共 13 个参数。q1 属于拉线固定端坐标可吸收的基座旋转自由度；q6、q7 在当前模型中为结构零列；末端 `d7 = 92.7026 mm + 49 mm = 141.7026 mm` 作为机械设定的有效轴向长度保持不变，避免把夹具常数吸收到机器人几何误差中。

## 使用与验收

1. 从交付目录启动 `HE3_RopeCalibration_V3_Tool_R6.1.exe`。
2. 必须使用新的 R6/R6.1 采集结果，不复用 8 月 17 日 V2 数据。
3. 上位机完成采集后查看右侧迭代记录及 `Result`/`log` 中的诊断文件。
4. 只有 MAE、最大残差、满秩、条件数、运动到位、20 次重复性、J7 扫描、19 点复测、参数物理范围和 R6.1 可观测性门限全部通过，保存按钮才会开放。
5. 第一次实机运行先只读取结果和日志，不直接写回控制器；确认参数方向、单位和前后残差后再决定写回。
