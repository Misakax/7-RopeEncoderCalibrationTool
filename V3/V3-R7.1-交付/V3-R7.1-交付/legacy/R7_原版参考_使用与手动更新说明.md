# HE3 拉线标定 R7：MDH 来源选择版

## R7 的目标

R6.5 在连接机器人后会立即用控制器回读值覆盖本地原始 MDH。R7 改为：

1. 连接时只读取控制器快照，不自动替换算法输入。
2. 点击“开始”时弹窗选择：
   - **是**：控制器真实 MDH；
   - **否**：原始 MDH（`Config/RobotType/HE3_GY-cfg.txt`）；
   - **取消**：不运动。
3. 选择后在右侧显示完整 MDH 和来源，需要第二次确认才能运动。
4. 选择控制器 MDH 时，增加 HE3 七轴结构检查：`D1/D6` 必须接近 0 mm，`D7` 必须在 75~110 mm，防止旧六轴写回再把 93 mm 写到 D6。
5. 写回前的候选参数也做相同的 D1/D6/D7 结构检查。

## 使用流程

1. 运行 `HE3_RopeCalibration_V3_Tool_R7.exe`。
2. 选择 `HE3_GY`，连接机器人。
3. 右侧日志会显示控制器只读快照，但还没有选它做输入。
4. 点“开始”，选择 MDH 来源。默认焦点是“否/原始 MDH”，避免误用未检查的控制器参数。
5. 检查右侧 `a/d/alpha/theta/beta`，再确认运动。
6. 计算后必须通过全部安全门才能保存。

## 两个选项分别是什么

- **控制器真实 MDH**：启动运动前现场读取 `1101.11`（D）、`1101.12`（旧式 Alpha）、`1127.13`（零位 count），转换为 Craig MDH 后计算。
- **原始 MDH**：软件选中机器人时从 `HE3_GY-cfg.txt` 读入的不可变快照。D7 在算法中是本体 D7 + 49 mm ToolOffset。

## 手动更新 R7 源码时要改的文件

1. `RopeEncoderCalibrationV3/RopeEncoderCalibrationDlg.cpp`
   - 版本标题、原始 MDH 快照、连接时只读、开始时选择、D1/D6/D7 检查。
2. `RopeEncoderCalibrationV3/RopeEncoderCalibrationDlg.h`
   - 增加 `SelectR7InputModelBeforeStart()` 声明。
3. `CalibrationV3Analytic/CalibrationV3Analytic.cpp`
   - `CalibrationV3BuildId()` 改为 R7，用于日志确认 EXE/DLL 没有混用。
