# 上位机接入说明

## 为什么不用旧 `Calibration(Eigen::MatrixXd, ...)` 接口

旧接口把 Eigen 对象按值跨 DLL 边界传递。只要 DLL 与上位机的编译器、运行库、
Eigen 配置或位数不一致，就可能在释放内存时产生 `0xC0000005`。

V3 导出 `CalibrationV3Analytic`，只传普通数组，调用方拥有全部输入输出内存。

## 输入排列

- `jointRad`：按点排列，`jointRad[point*axis+joint]`；
- 所有关节角：弧度；
- `a,d`：米；
- `alpha,thetaFixed,beta,q0`：弧度；
- `ropeRawM`：原始显示值从 mm 转成 m，但还未加 62.5 mm；
- `ropeFixedOffsetM`：HE3 V1 约定为 `0.0625`；
- `d7`：已包含 49 mm，约 `0.1417026`；
- `fixtureLocalXYZ`：采用 V1 折入 d7 的模式时传 `{0,0,0}`。

## 输出

- `outA/outD/outAlpha/outQ0`：完整 N 轴新参数；
- `outDelta4N`：布局 `[a|d|alpha|q0]`；
- `residualBeforeM/residualAfterM`：每个点的拉线残差，单位 m；
- `CalibrationV3Report`：迭代次数、秩、条件数、前后 MAE、固定端坐标。

## 上位机必须做的安全判断

即使 DLL 返回成功，也不能无条件写回机器人。至少检查：

1. `jacobianRank == activeCount`；
2. 条件数不超过项目阈值；
3. 标定后 MAE 确实下降；
4. 参数修正处于机械允许范围；
5. 输出中没有 NaN/Inf；
6. J6/J7 等不可观测参数保持原值；
7. 写回前保存原始 robot1.xml，可一键回滚。

## 七轴界面映射

旧 V1 界面只有 6 个长度槽和 6 个零位槽，不能直接表达完整七轴结果。临时兼容时可
把末端长度槽改为 d7，并保留 q7 原值；正式量产界面应显示完整 7 个 q0，并明确每个
长度槽对应的真实 DH 参数，禁止继续依赖 `m_CalibResult[5]` 这类含义不透明的下标。
