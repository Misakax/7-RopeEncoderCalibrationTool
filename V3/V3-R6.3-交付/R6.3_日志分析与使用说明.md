# HE3 拉线标定 R6.3

## 本次日志结论

- R6.2 实机有效求解点为 82 个，满秩 `15/15`，条件数约 `2121`。
- 第一次 MAE：`1.3909 -> 1.0231 mm`，最大残差：`3.3859 mm`。
- 单点 20 次采样的平均标准差约 `0.000074 mm`，最大约 `0.001746 mm`。编码器抖动远小于 1 mm 模型残差，20 次读取没有实际收益。
- 旧 100 点中的 61～78 是 J7/重复性诊断点，本来就不参与最小二乘，因此从量产运动序列移除不会损失辨识信息。
- 只保留原 V1 的 60 点会退化到约 `3.27 mm`，所以 J2～J5 的 22 个独立激励点必须保留。
- 原第 89 点 J3 目标 `+30°` 实际只能到约 `+27.611°`，R6.3 将该目标改为 `+25°`，避免软限位导致运动门限失败。

## R6.3 改动

1. 恢复 V1 的紧凑主界面，不再把窗口向右扩展；详细迭代仍保存在日志/CSV。
2. 保留两个小按钮：`复输入检验`、`恢复初始`。
3. 点位从 100 减为 82：原 60 点 + J2～J5 独立激励 22 点。
4. 每个静止点从 20 次读取减为 5 次，仍取平均并记录标准差。
5. 条件数门限按该 82 点实测满秩设计由 1000 调整为 2500；满秩、残差、运动误差、物理修正范围等门限仍保留。
6. DLL Build ID：`HE3-V3-CRAIG-MDH-ANALYTIC-LASER-PRIOR-20260825-R6.3`。

## 复输入检验的含义

第一次求得的完整 MDH 和零位被临时作为第二次输入，并在同一批测量数据上重新计算。R6.2 数据离线复放为：

- 第一次：约 `1.3909 -> 1.0231 mm`
- 第二次：约 `0.9612 -> 0.6646 mm`

但第二次会把 `d4` 相对原始模型的累计修正推到约 `+5.99 mm`，超过单轮基于激光样本设置的 `3 mm` 物理边界。因此 R6.3 把第二次定义为收敛性诊断：

- 不运动机器人；
- 不写机器人；
- 不替换第一次可保存结果；
- 单独生成 `V3Diagnostic_*_feedback2.csv`。

同数据第二次变小不能证明真实绝对定位精度同步变小，独立精度仍需新姿态或激光跟踪仪抽检。

## 操作

1. 运行 `HE3_RopeCalibration_V3_Tool_R6.3.exe`。
2. 正常连接、获取零点并运行 82 点。
3. 计算后先看标定前后 MAE、日志中的 rank/condition/gate。
4. 如需检查二次收敛，点击 `复输入检验`；它只复算已有数据。
5. `恢复初始`只恢复程序内存中的本次初始 MDH。

注意：R6.3 不会由测试程序自动发起运动；机器人运动仍由操作员点击“开始”触发。
