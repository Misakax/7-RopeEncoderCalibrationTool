R7.1 offline algorithm replay against shipped 82-point R7 diagnostic
=====================================================================

Purpose
-------
Validate the R7.1 math change without pretending a Windows DLL was rebuilt.
The Python mirror follows the shipped C++ equations for Craig FK, exact point
Jacobian, V1 adjacent-sphere anchor initialization, Huber weighting, weak priors,
pseudoinverse, backtracking, and hard correction limits.

Condition gate note
-------------------
R7 used <=2500 with 15 robot + 3 anchor columns. Adding bL creates a 19th
physical nuisance column and raises the same data to about 2636. R7.1 therefore
uses <=3000 while preserving the full augmented-rank requirement.

Important safety note
---------------------
This replay predicts MAE < 1 mm, but the geometry optimizer can still push one
or more MDH parameters toward/outside the eight-robot laser population envelope.
The laser-envelope gate remains independent and can still reject writeback.
